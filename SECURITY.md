# Security

Report suspected vulnerabilities through
[GitHub's private vulnerability reporting form](https://github.com/xinvexo/egrio/security/advisories/new).
Please keep vulnerability details out of public issues and pull requests, and
coordinate disclosure privately.

Include the Egrio version or commit, affected platform, potential impact,
reproduction steps, and a minimal configuration or redacted logs when useful.
Do not submit real node credentials, subscription tokens, private keys, or
other personal information.
