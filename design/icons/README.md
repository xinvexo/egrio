# Egrio 图标

桌面图标、Windows 任务栏、macOS Dock 与 Linux 程序坞使用白色圆角底上的冰蓝雪花，带冰晶切面、高光与柔和阴影。
安装、卸载程序的文件与任务栏图标也使用这份图稿。应用界面与安装页里的雪花展示使用独立的透明底图稿，融入所在
页面的背景；Windows 界面左上角与 NSIS 的窗口标题栏、侧栏、页头使用它。

Windows 与 Linux 托盘共用透明底的冰晶雪花：系统代理或 TUN 模式开启时为冰蓝色，带定向明暗、倒角高光与中心亮点；
两层都关闭时为银灰色。macOS 菜单栏使用笔画更细的黑色雪花模板图：开启时不透明，关闭时为同一雪花的 42% 不透明度，
由系统按菜单栏的外观着色。

## 原稿

- `app-icon.png`：1024 × 1024，桌面、任务栏与 Dock 使用的带底板应用图标母版。
- `app-mark.png`：1254 × 1254，应用界面与安装页使用的透明底雪花母版。
- `tray/on/`、`tray/off/`：Windows 与 Linux 共用的原尺寸 PNG，开启与关闭各一套，包含 16、20、24、32、48、64、
  128 与 256 px。保留各尺寸的像素，生成时不再缩放。
- `tray-macos-on.png`：44 × 44，开启捕获时的 macOS 菜单栏模板图。
- `tray-macos-off.png`：44 × 44，关闭捕获时的 macOS 菜单栏模板图。

修改原稿后，在项目根目录运行：

```sh
cargo xtask icons
```

生成器把结果写入 `../../desktop/egrio/icons/`。应用图标与界面展示图在预乘 alpha 上分步进行双三次缩放，保留透明
边缘；托盘的原尺寸 PNG 原样封装或复制：

- `icon.ico`：Windows 可执行文件、桌面与任务栏，以及 NSIS 安装、卸载程序共用的带底板图标，含 16–256 px
  的八种尺寸。
- `app-mark.ico`：Windows 界面与 NSIS 窗口标题栏使用的透明底雪花，含 16–256 px 的八种尺寸。
- `32x32.png`、`48x48.png`、`128x128.png`、`256x256.png`、`512x512.png`：Linux hicolor 的带底板应用图标。
- `icon.icns`：macOS 应用包图标，母版居中缩到 824 px，四周留 100 px 透明区；16 与 32 px 用 ARGB 表示，其余用 PNG。
- `tray-on.ico`、`tray-off.ico`：Windows 通知区域图标，封装原稿的全部八种尺寸，按系统显示缩放选择。
- `tray-on-<size>x<size>.png` 与对应的 `tray-off` 文件：Linux 托盘图标，复制原稿的 16、20、24、32、48、64 与
  128 px，由面板按显示尺寸与缩放选择。
- `tray-macos-on.png`、`tray-macos-off.png`：macOS 菜单栏的 44 px 模板图，按 22 pt 显示；可见雪花约 17 pt，四周留透明边缘。

Windows 打包时把透明底雪花合成到安装页本身的白色背景上，生成 24 位 BMP：侧栏按 164 × 314、雪花 128 px 的布局，
为 100%–300% 的八种显示缩放分别生成；页头按 150 × 57、雪花 40 px 的布局以三倍像素生成，由 Modern UI 缩放到
控件大小。图案周围直接呈现安装页底色。

原稿与生成的图标一起提交，普通构建无需重新生成。
